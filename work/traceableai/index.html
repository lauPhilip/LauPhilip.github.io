TraceableAI: Literature Reviews With Checked Citations

Literature reviews written by AI, where every citation can be checked. For each cited sentence, it shows the passage in the paper that supports it, or says plainly that it found none.

The problem

A literature review reads the published research on a question and sums up what it says, citing each paper it relies on. Ask a language model to review the literature, and you get fluent text with citations that are often wrong, mismatched or invented. Researchers cannot trust a review they cannot check.

What I built

A web app that runs a full PRISMA 2020 systematic review. You type a research question and your criteria. It writes the review protocol before it searches, searches open scholarly databases, screens every record twice, reads the open-access full texts and groups the findings into themes. Then it writes the report and checks every citation against the paper it cites.

The result

Across 20 completed reviews, TraceableAI checked 1,732 citations. 74% of them were supported by their source, and 80% of the included studies were cited in the final text. Two screening agents agreed with a Cohen's kappa of 0.81. The paper is accepted at OSSYM 2026, the 8th International Open Search Symposium at CODE University in Berlin. The tool is open source under Apache 2.0, live on its own website, and each release is archived with a DOI on Zenodo.

For engineers: how it works

ASP.NET Core and Blazor on .NET 10, in C#. The model is Mistral through its API, or a local model through Ollama. The code is grouped by review stage: Sources (arXiv, OpenAlex, Semantic Scholar, Crossref, and Scopus and IEEE Xplore with a key), Search, Screening, Evidence, Synthesis, Verification and Report. Every model answer is JSON that is validated in code. A citation verdict counts only when its supporting quote is found word for word in the paper. A sentence that claims more than its source is rewritten and checked again, and an unsupported citation is removed. Counts, the methods section and the PRISMA flow diagram are written by code from what the run did, never by the model. Screening runs twice with independent prompts, and agreement is reported as Cohen's kappa. Each run keeps its protocol, raw database responses, every decision and every model call on file, fingerprinted with SHA-256 and downloadable as one archive with a LaTeX manuscript and BibTeX and RIS files. Text from papers is treated as data: hidden text is stripped and phrases that try to steer the model are flagged. Other tools can start a review through a REST API or an MCP server. The xUnit tests run offline against a scripted fake model.
