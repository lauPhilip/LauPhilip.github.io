Coursebot: AI Course Assistants for Teachers

A platform where university teachers set up an AI chatbot for their course, without writing code. Students ask it questions, and it answers only from the course material.

Where
Aarhus University
My role
Main developer (frontend, backend, design and testing)
Status
Ongoing

The problem

General AI chatbots answer from anywhere, not from what is taught in the course. Teachers also cannot see what their students ask them.

What I built

I build the frontend and backend, design the interface and test the platform. A colleague runs the server and database. Teachers add their course material and create a bot for each course or lecture. The bot only answers from that material, so students get guidance that matches the teaching. Teachers can see what students ask and how well the bot helps.

The result

In development for bachelor's and master's programmes. The source code is private.

For engineers: how it works

Laravel (PHP) backend with a Vue frontend, styled with SCSS. SQLite for local development and PostgreSQL in deployment. Teachers create one bot per course or lecture in a web interface, with no code. Answers are grounded in the uploaded course material with retrieval-augmented generation (RAG). An analytics view shows what students ask and how each bot performs. I build the frontend, backend, design and tests, and a colleague runs the server and database. The source code is private.

Technologies: Laravel, Vue, PHP, PostgreSQL, RAG, Generative AI
