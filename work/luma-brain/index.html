LUMA Brain: A Language Model From Scratch

The "brain" behind LUMA. It is a small AI language model that I am building step by step, so the assistant can one day run fully on my own computer.

The problem

LUMA depends on a ready-made model today. I want it to work offline and keep my data private.

What I built

I am learning how language models work from the inside by building one. I follow Sebastian Raschka's book "Build a Large Language Model (From Scratch)". The goal is a small, fast model trained on my own data and on LUMA's skills.

The result

Work in progress. The code is private for now.

How it works

I work through the book chapter by chapter and write every piece myself instead of calling a hosted API. That covers tokenization and data loading, self-attention and multi-head attention, the GPT-style transformer block, pretraining on unlabeled text, and fine-tuning for classification and instruction following. The goal is a lightweight model that runs well on CPU or GPU, trained on my own data and on LUMA's tools and skills, so the assistant can answer and act offline. The source code is private.

Technologies: Python, PyTorch, Transformers, Tokenization, Pretraining, Fine-tuning, LLM
