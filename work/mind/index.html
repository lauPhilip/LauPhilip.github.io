MIND: AI Search Assistant for LEGO Engineers

An AI assistant used by 331 engineers at the LEGO Group to search their technical documentation. Each answer shows the document it comes from.

The problem

Mould engineers lost time looking for answers in large libraries of internal standards and technical manuals.

What I built

In my master's thesis, I wrote most of the code and took MIND from prototype towards a product. It uses exact keyword search for technical terms and meaning-based search for everyday questions. It then picks the most relevant passages and writes a short answer with references to the source.

The result

MIND is used by 331 engineers at the LEGO Group to search their technical documentation. It covers core documentation for element, mould development and mould construction. The proof of concept was estimated to save 240 hours.

How it works

For engineers. Each question passes through five steps before the answer reaches the user.

  1. QuestionThe engineer asks in plain language
  2. Query rewritingThe question is rewritten for search
  3. Hybrid retrievalBM25 for exact terms plus vector search for meaning
  4. RerankingA cross-encoder keeps the best passages
  5. Answer with sourcesInline references to each source document

Retrieval is hybrid. BM25 keyword search finds exact technical terms, and dense vector search finds passages with the same meaning in different words. The results are merged, and a cross-encoder reranker orders them. A query-rewriting step improves the search query. The language model answers only from the top passages and adds inline references, so each answer links back to its source passage. The code, data, usage figures and evaluation results are under a non-disclosure agreement with the LEGO Group, so I cannot share them here. I am happy to explain the design and the evaluation method in an interview.

Technologies: RAG, Hybrid retrieval, BM25, Vector search, Reranking, Query rewriting
