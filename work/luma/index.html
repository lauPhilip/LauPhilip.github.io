LUMA: Personal AI Desktop Assistant

My personal AI assistant for the desktop. Say "Luma" to wake it. Then you can chat, check the news and markets, use the camera, run commands or play music.

The problem

I wanted one assistant for chat, news, music and commands that runs on my own computer instead of in the cloud.

What I built

LUMA has five tools on a bar at the bottom of the screen: a live news and markets feed, a chat window for voice or text, a camera view, a command terminal and a music player connected to Spotify.

The result

A working desktop app that answers with a local model today. Version 1 is public on GitHub. The current version is private.

How it works

The frontend is a PyQt6 desktop app built around a central animated core and five modules on a bottom dock. World Feed shows a live TV stream, a market ticker and chart, a top story and headlines. Chat takes voice or text and uses draggable glass-style panels. Optic shows the live camera. Terminal runs Luma's own commands and skills. Music shows what is playing on Spotify and controls playback. Replies come from a local model through Ollama today. Later, I plan to swap in LUMA Brain, the small language model I am building from scratch. The source code is private.

Technologies: Python, PyQt6, Ollama, Voice and wake word, Local AI, Spotify, Desktop UI
