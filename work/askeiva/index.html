AskEIVA: AI Support Assistant for EIVA

An AI assistant built to help EIVA's customer service team find answers. It searches the company's technical manuals and past support tickets.

  • GitHub repository
Where

Developer, together with EIVA
Status
Finished

The problem

Answers to customer questions were spread across large technical manuals and old support tickets. Finding them by hand takes time.

What I built

I first built a quick prototype in Python to prove the idea worked. Then I rebuilt it in C# and .NET. The business logic, the database and the user interface are kept apart, so the code is easier to test, extend and hand over. The web app lets staff chat with the assistant, configure it and check the quality of its answers.

The result

Handed over to EIVA's IT department for configuration and roll-out. The code is public on GitHub.

For engineers: how it works

I rewrote a single-file Python prototype as a C# solution with Clean Architecture in four layers. Domain holds the core types and rules. Application holds the use cases. Infrastructure talks to Weaviate Cloud for vector storage and search, and to the database. The web interface is Blazor Interactive Server. Long-running work runs as background services, outside the user's request. The trade-off is more structure up front, in return for strict typing and code that is safer to change and hand over. The app includes evaluation screens for checking answer quality.

Technologies: C#, .NET 10, Blazor, Weaviate, GraphRAG, Clean Architecture
